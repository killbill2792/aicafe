Self-hosted web fonts, so builds never depend on downloading from Google Fonts.
All three families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):
- Plus Jakarta Sans (latin subset, variable weight 500–800)
- Inter (latin subset, variable weight 400–700)
- IBM Plex Sans Arabic (arabic subset, weights 400, 500, 600, 700)
Files come from the Google Fonts CSS2 API (same files `next/font/google` used). Loaded in `app/[locale]/layout.tsx`.
