## U5-01 — root cause, repair and regression coverage

1. **Source:** `agentRunner.server.ts` advertised only the last six owner-message IDs in the newest paginated page. The selected ID had to be a member of that one small set; even a valid original objective in an older owner message was rejected. Omitting the ID when no earlier owner appeared in the newest page could save the current scheduling-only message. Persisted original text is read from `ai_messages` by the U4 database; this is a discovery/continuity bug, not lost storage.
2. **Test-first reproducer:** `routines.test.ts` adds `list_goal_sources` on page offset 50. Red on `549a8960`, GitHub Actions [#44912943377](https://github.com/killbill2792/aicafe/actions/runs/44912943377), Vitest shard 3/3 failed because both action and offset were not accepted. The red regression did not change production behavior.
3. **Smallest existing-path repair:** `manage_routine` gains on-demand paged authenticated owner-message previews using `ConversationService.listMessages`. No new registered tool, table, cron or engine. Luna selects any discovered original goal source ID, and existing server/SQL validate same owner/café/thread and preserve full text. Model preview remains capped to eight recent candidates by default and 320-character previews; paging retrieves earlier IDs on demand without dumping a full conversation in every prompt. A scheduling-only reply with older pages cannot silently replace an unselected original.
4. **Assertions:** `routines.test.ts`: page offset/cursor, source selection and no unauthorized port, invalid offsets; `routineGoalSources.test.ts`: more than six owner turns, other thread, assistant-authored, later timestamps, empty messages, preview/full objective separation, explicit source selection on older pages. Existing `routines.db.test.ts` remains the full-text identity/replay/tenant oracle. Need final-head app/DB/run proof before marking IV.
5. **Authorization and dependency:** `goalSourceIds` admits only IDs returned from trusted authenticated pages. U4 SQL independently confirms persisted source and exact owner/thread. No effect permission is conveyed by a source candidate. #533 must synchronize `tools/index.ts` after U5 merge; #534/#535 through their already-stacked branch chain. #542 independent.
